Project 3

Omschrijving

Voor dit project heb ik een fysiek thuisnetwerk volledig opnieuw ingericht en logisch gesegmenteerd. Het doel was om IoT-apparaten, privé-werkstations en een gastennetwerk strikt van elkaar te scheiden om de veiligheid te verhogen.

Technologieën

Cisco Packet Tracer pfSense Firewall DHCP / DNS

Resultaat

Het netwerk draait nu stabiel met drie gescheiden VLAN's. Routering gebeurt efficiënt via een Layer 3 switch en de firewall regels blokkeren ongeautoriseerd verkeer tussen de segmenten succesvol.
